# 苍穹拼图模板

两套模板均由苍穹自己的解析几何绘制，不读取或包含上游模板图片。生成源码见 `scripts/generate-templates.php`，按仓库 Apache-2.0 许可证分发。

- `slider_1`：圆角主体、上凸圆榫、右侧圆形凹口。
- `slider_2`：圆角主体、左凸圆榫、顶部圆形凹口。
- 每套固定为 110×110；`mask.png` 定义裁切覆盖率（含半透明边缘），`fixed.png` 绘制缺口阴影，`active.png` 绘制拼图块亮边与倒角。块内保留背景原图纹理。

在仓库根目录执行 `composer templates:generate` 可重新生成六张 PNG，并更新 `resources/manifest.json` 中对应的 SHA256。生成仅需 PHP/GD，不输入外部素材。此命令用于修改素材后的开发流程，运行时直接加载 PNG，不逐请求绘图。

`tests/TemplateRenderingTest.php` 检查两套形状的凸凹定位、透明边界、24200 个裁切像素，以及极亮／极暗背景下的轮廓可见性。题型生成与答案校验另由协议测试覆盖。外观改变不调整校验容差或新增默认干扰缺口。

绘制先以四倍尺寸采样，再缩小为 110×110，保留抗锯齿透明度；裁切同样保留该覆盖率。边缘仅作窄范围平滑，不对背景照片或整个拼图块施加模糊。测试另检查曲线半透明边缘的数量范围和透明源图的 Alpha 合成。
