# Bundled landscape backgrounds

No external stock-photo service, identifiable person, customer content or existing fictional character is used. These are not Tianai's upstream photographs. The generation interface did not expose an independently verifiable model version.

Shared prompt requirements: original standalone landscape, 5:3 aspect ratio, no text, logos, watermarks, CAPTCHA controls or puzzle holes; enough local detail for image challenges.
